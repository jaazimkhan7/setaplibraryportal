**User Requirements**

UR-S01
Students should be able to check the availability of books without visiting the physical library.

UR-S02
Students should be able to track their history and add books to favourite lists.

UR-S03
Students should be able to access learning resources, including books, e-books, PDFs, and educational videos.

UR-S04
Students should be able to listen to books through artificial intelligence audio narration.

UR-S05
Students should be able to create flashcards, summary notes, and concept notes based on book content.

UR-L01
Librarians should be able to maintain student records and borrowing records.

UR-L02
Librarians should be able to maintain the accession register.

UR-L03
Librarians should be able to generate department-wise reports of books.

UR-L04
Librarians should be able to create requisition forms for purchase of books.

UR-L05
Librarians should be able to generate monthly issue and return books.

UR-A01
Administrators should be able to manage student and librarian accounts.

UR-A02
Administrators should be able to give permission depending on the roles of the users.

UR-A03
Administrators should be able to generate reports and access the library dashboard.

UR-A04
Administrators should be able to limit borrow periods and due dates.

UR-A05
Administrators should be able to set the number of fines for daily overdue books.

**Non Functional Requirements**

NFR-01
Performance
The system should display search results for books within 3 seconds in 95% of cases under normal operating conditions.

NFR-02
Security
The system must authenticate access to personal user accounts.

NFR-03
Access control
The system must prevent users from accessing functions beyond their authorization in any access control tests.

NFR-04
Reliability
At least 99% of valid operations of issue and return of books must be completed successfully.

NFR-05
Data integrity	
The system shall ensure consistency in book availability and lending information after each successful issue or return process.
